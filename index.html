Skill File Checker

Paste an AI skill, rule or instruction file (SKILL.md, AGENTS.md, CLAUDE.md, .cursorrules, README set-up guides) and get a plain-English list of things worth checking before you or your assistant follow it.

Private by design. Everything runs in your browser. Nothing you paste is uploaded, stored or sent anywhere, and this page is locked so it cannot connect to the internet. It is a first check, not a guarantee: it matches known patterns, so a clean result does not mean a file is safe.
